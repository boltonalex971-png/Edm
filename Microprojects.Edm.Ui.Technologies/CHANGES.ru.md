# Основной UI EDM — изменения для пользователей

Основной UI — это домашний экран EDM: панель управления, мастер New Operation, деревья настроек (рабочие места, устройства, профили, процессы, аудиты) и карточка операции с отчётами по сенсорам. Смонтирован в корне сайта.

## v2.0.0.0

- **Деревья настроек теперь используют глобально уникальные ID.** Записи хостов, устройств, процессов и рабочих мест перешли со старых поверх-таблицы целочисленных счётчиков на стабильные Guid ID, уникальные в рамках всей платформы. Старые закладки на `/api/technologies/hierarchies/...` нужно пересохранить под `/api/technologies/directories/...`; внутренние ссылки в приложении обновляются автоматически. Каждая редактируемая сущность (хост, устройство, процесс, рабочее место, профиль, квалификатор, аудит, операция, верстак) теперь хранит, кто её создал или изменил, а удалённые записи мягко скрываются вместо стирания, чтобы исторические операции и измерения сохраняли контекст. <!-- cite: F-global-directories -->
- **Перетаскивание теперь приземляется в осмысленное место.** В деревьях устройств, рабочих мест, хостов и процессов перетаскивание узла на пустое пространство вне любой цели раньше не делало ничего; теперь перемещение делает fallback на видимый локальный корень. Удаление папки также сразу обновляет дерево. <!-- cite: PR #70 -->
- **Переключатель плотности масштабирует всё окно.** Compact, Comfortable и Touch теперь меняют размер текста, отступов и иконок вместе — выберите плотность под свой экран, и весь интерфейс подстроится. <!-- cite: PR #65 -->
- **Обновлённый внешний вид по всему сайту.** Главная страница, разметка master/detail, деревья настроек, карточка операции и панель управления получили новый внешний вид, общий с Консолью и Логистикой; переключение плотности и светлой/тёмной темы доступно из меню пользователя. <!-- cite: PR #55 -->
- **Деревья настроек снова ведут себя как задумано.** Выделения, панель деталей и разметка дерева больше не съезжают. <!-- cite: PR #45 -->
- **Запуск операции из меню Operation снова работает.** Действие запуска больше не теряется. <!-- cite: PR #42 -->

## v1.13.28

- **Мастер New Operation выбирает правильный процесс каждый раз.** Папка и процесс с одинаковым числовым id больше не путают выбор. <!-- cite: PR #41 -->

## v1.13.0

- **Доводка панели управления.** Операции окрашены по статусу; список завершённых сегодня отфильтровывает вчерашний шум; корневая панель разворачивается до выполняющихся операций по процессам; отменённые строки показывают, *когда* были отменены; добавлено представление завершённых за 7 дней; строки сортируются по дате завершения / отмены. <!-- cite: PR 793, PR 795, PR 796, PR 797, PR 798, PR 800 -->
- **Контекстное меню и копирование операции.** Правый клик по операции открывает её, отменяет или копирует; любую завершённую операцию можно использовать как основу для новой одним кликом. <!-- cite: PR 783, PR 804 -->
- **Исправления редактора и алертов.** Редактор опций драйвера показывает правильную схему даже после замены драйвера устройства; редактор критерия сохраняет значения при прокрутке; поля, отключённые условием, по-прежнему сохраняются; алерты можно закрывать, и они больше не блокируют страницу. <!-- cite: PR 754, PR 755, PR 765, PR 790 -->
- **В отчётах — самое свежее измерение сенсора.** Больше никаких произвольных отсчётов из середины выполнения. <!-- cite: PR 748 -->
- **Более плавный старт операции.** Статус меньше мигает, пока задачи и устройства инициализируются. <!-- cite: PR 784 -->
- **Обработка поставок.** Редактирование и потребление поставок, привязанных к процессу, прямо из основного UI. <!-- cite: PR 715 -->
- **Редизайн UI технологий.** Переорганизован вокруг производственных процессов, со сгруппированными вместе сортами и спецификациями; legacy-вид заменён — закладки могут потребовать обновления. <!-- cite: PR 825 -->

## v1.12.5

- **Исправления сохранения.** Правки опций драйвера теперь сохраняются, а параметры, набранные в мастере, доходят до устройства при старте. <!-- cite: PR 589, PR 590 -->
- **UX карточки операции.** Отдельный × на карточке операции закрывает её без потери прокрутки; отвязка процесса от рабочего пространства отражается сразу. <!-- cite: PR 586, PR 666 -->
- **Обработка дат.** Время показывается в вашей локали. <!-- cite: PR 680, PR 681 -->
- **Более тихий вход и навигация.** PWA-манифест доступен и в авторизованном, и в неавторизованном потоке; фантомная ошибка при каждой навигации устранена. <!-- cite: PR 628, PR 667, PR 668 -->
- **Более быстрое погружение в сенсор.** Страницы сенсоров загружаются по требованию, а не вытягивают отчёт целиком. <!-- cite: PR 684, PR 690 -->

## v1.12.0

- **Мастер New Operation доведён.** Мастер надёжно переносит выбранный workbench / устройство к запуску; перезапуск больше не создаёт дубликат операции. <!-- cite: PR 567, PR 604 -->
- **Проверка «equals» в аудите.** Аудиты могут сравнивать два параметра на равенство, а не только диапазоны. <!-- cite: PR 579 -->
- **Вкладка зон аудита в карточке.** Зоны — соседняя вкладка карточки операции, а не глубоко в опциях аудита. <!-- cite: PR 573 -->
- **Универсальная панель управления.** Карточки операций используют ту же панель Start / Cancel / Done, что и приложения операций. <!-- cite: PR 558 -->
- **Подразделения пользователей.** Фильтрация операторов по подразделению заменяет прежнюю проверку роли. <!-- cite: PR 608 -->
- **Список активных хостов показывает реальное состояние.** Живые хосты помечаются как таковые; устаревший вид устранён. <!-- cite: PR 610 -->
- **Переключение роли перерисовывает меню.** Выбранная роль отражается сразу. <!-- cite: PR 568 -->
- **Удалённые рабочие места скрыты в picker'е старта процесса.** <!-- cite: PR 578 -->

## v1.0.0

- **Первый релиз.** Рабочие места, операции и разделы настроек, которые расширяют другие плагины. <!-- cite: PR 218, PR 226, PR 228 -->
- **Связка workbench / процесс.** New Operation предлагает только устройства, чей профиль допускает выбранный процесс; профили различают входные и выходные параметры, и мастер собирает только входные; профиль, привязанный к workbench, виден в строке устройства. <!-- cite: PR 368, PR 371, PR 372 -->
- **UX жизненного цикла операции.** Карточка операции показывает опции устройства, активные на момент старта; брошенные операции можно принудительно завершить из карточки; правки в другой вкладке шлют уведомления всем, у кого открыта карточка. <!-- cite: PR 284, PR 422, PR 498 -->
- **Аудит по шаблонам.** Зоны аудита берутся из шаблона, который редактируется однократно, вместо копирования из операции в операцию. <!-- cite: PR 294 -->
- **Обновление UI.** Перетаскивание в дереве больше не выделяет половину текста страницы; ведущий `0` в поле детали процесса больше не «съедается». <!-- cite: PR 367, PR 382, PR 386 -->
- **Исправление привязки хоста.** Привязка хоста к устройству сразу обновляет строку устройства. <!-- cite: PR 380 -->
- **Точки входа в оператор-десктоп.** Кнопки запускают UI оператора и общее приложение оператора Optosense. <!-- cite: PR 432, PR 435 -->
- **Доводка интеграции ISL.** Связки с системой ISL работают сквозным образом. <!-- cite: PR 431 -->
