# Драйвер OPC UA и профиль Environment — изменения для пользователя

Плагин включает две части:

- профиль **Environment** (`profiles/environment`) — описание того, какие данные забирать с OPC UA-сервера;
- драйвер **OPC UA** (`drivers/opcua`) — устройство, которое подключается к серверу и получает значения во время операции.

## v1.13.0

- **Исправлена передача значений между драйверами.** Значения корректно проходят по цепочке OPC UA → Operator → Optogen и больше не теряются. <!-- cite: PR 723 -->

## v1.0.0

- **Плагин впервые выпущен.** Подключите EDM к любому OPC UA-серверу, выберите узлы в редакторе профиля Environment и используйте их значения как параметры устройства во время операций. <!-- cite: PR 428 -->
- **Собственные и профильные параметры.** Добавляйте к драйверу пользовательские параметры поверх профиля, подхватывайте новый параметр профиля в параметрах драйвера без перезагрузки страницы и видите *имена* профилей вместо GUID в списке устройств на рабочем месте. <!-- cite: PR 441, PR 460, PR 461 -->
- **Повышенная устойчивость.** Неожиданные типы данных узлов больше не приводят к аварийному завершению драйвера, сессии OPC UA корректно закрываются при остановке (соединения не утекают), а числовые значения сохраняют исходный тип, а не приводятся к decimal. <!-- cite: PR 430, PR 447, PR 463 -->
