# Консоль хоста — изменения для пользователей

Консоль хоста (`/console`) показывает, что происходит на одном хосте EDM: привязанные устройства, драйверы, доступные и выполняющиеся задачи, а также живой журнал.

## v2.0.0.0

- **Обновлённый внешний вид, как у остальной платформы.** Консоль теперь использует те же цвета, шрифты, плотность и отступы, что Технологии и Логистика. <!-- cite: PR #69 -->
- **Переключатель плотности масштабирует всё окно.** Compact, Comfortable и Touch теперь меняют размер текста, отступов и иконок вместе — выберите плотность под свой экран, и весь интерфейс подстроится. <!-- cite: PR #65 -->
- **Консоль также может жить внутри Хаба.** Те же экраны Консоли доступны отдельно по адресу `/console` или встроены вкладками в Хабе; индикатор подключения к хосту виден в заголовке в обоих случаях. <!-- cite: PR #54 -->

## v1.0.0

- **Просмотр устройств, драйверов, задач и журнала по одному хосту.** Списки обновляются в реальном времени; индикатор состояния показывает, доступен ли хост. <!-- cite: PR 309, PR 443 -->
- **Терминология задач.** Операции содержат задачи; задачи нацелены на устройства. Существующие панели продолжают работать. <!-- cite: PR 344, PR 347 -->
