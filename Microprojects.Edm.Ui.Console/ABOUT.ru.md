# Консоль хоста

Эксплуатация самой платформы: текущее состояние задач и драйверов, поток журналов из процесса хоста, состояние плагинов, справка по установленным компонентам.

Сюда заходят администратор или оператор, чтобы узнать, что хост делает прямо сейчас, и вмешаться, когда что-то идёт не так.

Консоль — это взгляд внутрь оболочки. Остальные модули — это работа; этот модуль — механизм, который её обеспечивает.
