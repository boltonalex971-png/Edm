# Optogen App — Изменения для пользователя

Optogen (`apps/optogen`) — универсальный интерфейс оператора. Запускается во время выполнения задачи, показывает текущие показания устройства, принимает ввод оператора и обменивается параметрами с драйверами.

## v1.13.0

- **Надёжная передача параметров.** Обмен с драйверами больше не теряет параметры, а действия оператора, отправленные в Optogen, сохраняются при перезагрузке экрана. <!-- cite: PR 723, PR 809 -->

## v1.12.0

- **Форматирование чисел для каждого выхода.** Задавайте точность и формат для каждого выходного параметра; разумные значения по умолчанию делают только что созданную операцию сразу читаемой; имена параметров с не-ASCII символами теперь сохраняются корректно. <!-- cite: PR 542, PR 543, PR 544 -->
- **Номер операции в заголовке.** В заголовке видно, к какой операции относится экран — удобно, когда открыто несколько. <!-- cite: PR 545 -->
- **Универсальная панель управления.** Общая панель Start / Cancel / Done, как в других приложениях операций. <!-- cite: PR 558 -->

## v1.0.0

- **Плагин добавлен.** Один настраиваемый интерфейс оператора на операцию, заменяющий отдельные экраны для каждого устройства. <!-- cite: PR 435 -->
- **Удобная работа с выходными параметрами.** Параметры из фиксированного списка отображаются выпадающим списком; числовые значения больше не округляются принудительно до двух знаков. <!-- cite: PR 458, PR 463 -->
- **Надёжные значения по умолчанию и сохранение.** Настройки Optogen открываются даже без записи параметров, сохраняются корректно и показывают имена профилей вместо GUID для устройств стенда. <!-- cite: PR 438, PR 442, PR 461 -->
- **Повторяемый шаг оператора.** Шаги, помеченные в профиле Operator как повторяемые, принимают ввод, пока оператор не перейдёт дальше. <!-- cite: PR 439 -->
