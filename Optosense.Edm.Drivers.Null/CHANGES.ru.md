# Драйвер Null — изменения для пользователя

Драйвер Null — устройство-заглушка, которое ничего не делает. Используйте его как временную замену, когда нужно настроить или проверить процесс, не управляя реальным оборудованием.

После v1.0.0 видимых пользователю изменений нет.

## v1.0.0

- **Первый выпуск.** Добавлен драйвер Null и минимальный экран параметров драйвера, который открывается при подключении Null к устройству на рабочем месте. <!-- cite: PR 266 -->
