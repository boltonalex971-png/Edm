# Null Driver — User Changes

The Null driver is a stub device that does nothing. Use it as a placeholder when configuring or testing a process that should not actually drive any hardware.

There are no user-visible changes after v1.0.0.

## v1.0.0

- **Initial release.** Adds the Null driver and a minimal driver-options screen shown when the Null driver is attached to a workbench device. <!-- cite: PR 266 -->
