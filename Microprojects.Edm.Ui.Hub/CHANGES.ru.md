# Хаб — изменения для пользователей

Приложение Хаба (`/`) — главная страница платформы EDM. Монтируется в корне URL и показывает плитку для каждого загруженного приложения, чтобы пользователи могли выбрать модуль для входа.

## v1.0.0

- **Первый релиз.** Главная страница с плиткой для каждого загруженного приложения — выберите модуль, чтобы войти. Сам Хаб скрыт из своего списка. В подвале отображается версия продукта.
