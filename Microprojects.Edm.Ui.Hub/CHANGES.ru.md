# Хаб — изменения для пользователей

Приложение Хаба (`/`) — главная страница платформы EDM. Монтируется в корне URL и показывает плитку для каждого загруженного application-плагина, чтобы пользователи могли выбрать модуль для входа.

## v1.0.0

- **Первый релиз.** Direction A · «стальной» hero с краткой сводкой системы плюс реестр плагинов в три колонки, перечисляющий каждый загруженный application-плагин (Logistics, Technologies, Console, …). Плитки ведут на корневой URL каждого плагина. Хаб скрыт из собственного списка. Статистика версии отражает `ProductVersion` установленного Setup MSI.
