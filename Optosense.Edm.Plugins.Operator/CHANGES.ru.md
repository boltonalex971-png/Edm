# Плагин Operator — изменения для пользователя

Плагин Operator позволяет человеку заменить любое устройство. Он включает:

- профиль **Operator** (`profiles/operator`) — описание шагов, которые должен выполнить оператор, с входными и выходными параметрами и условиями;
- драйвер **Operator** (`drivers/operator`) — подключается к устройству на рабочем месте и принимает ввод человека там, где обычно отвечает оборудование;
- экран операции **Operator** (`apps/operator`) — то, что оператор видит во время выполнения задачи.

## v1.13.0

- **Стабильнее жизненный цикл устройства.** Устройства реже зависают, отмена выполняется быстрее, а завершение устройства после последнего шага оператора теперь корректно закрывает операцию, а не оставляет её в состоянии «ожидание». <!-- cite: PR 756, PR 809, PR 814 -->
- **Исправлена передача значений между драйверами.** Обмен с драйвером OPC UA и экраном Optogen больше не теряет значения. <!-- cite: PR 723 -->

## v1.12.0

- **Интеграция с TypeOne.** Плагин предоставляет настроечный слот, который приложение TypeOne использует для сопоставления шагов оператора с проверками датчиков. <!-- cite: PR 570 -->

## v1.0.0

- **Плагин впервые выпущен.** Замените любое устройство в процессе человеком, который вручную выполняет шаги и вводит показания. <!-- cite: PR 381 -->
- **Гибкая настройка шагов.** Шаги поддерживают условия на основе ранее заданных параметров, дедлайны с обратным отсчётом, повторяемый ввод и доступ к другим параметрам того же устройства; условие, ссылающееся на незаданный параметр, теперь вычисляется как ложь, а не приводит к ошибке. <!-- cite: PR 429, PR 433, PR 434, PR 439, PR 440 -->
- **Ответы оператора попадают в отчёт.** Ответы возвращаются в параметры операции так же, как показания приборов, и каждый ответ несёт значение `ResponseTime`, которое отображается в аудите и отчёте. <!-- cite: PR 384, PR 432 -->
- **Исправлена отмена.** Отмена операции, ждущей шага оператора, больше не подвешивает задачу. <!-- cite: PR 388 -->
