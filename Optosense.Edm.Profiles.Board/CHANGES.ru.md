# Board Profile & Mux Driver — Изменения для пользователя

Плагин содержит:

- профиль **Board** (`profiles/board`) — описание последовательности команд и инструкций для платы и того, какие параметры возвращает каждая из них;
- драйвер **Mux board** (`drivers/mux`) — управляет 20-сокетной MUX-платой через последовательный порт, выполняя план, сформированный из профиля Board.

## v1.13.0

- **Более стабильная работа с последовательным портом на медленных линиях.** Настраиваемая пауза перед инструкцией не даёт плате терять первые символы, а активные задачи Mux корректно останавливаются при завершении или отмене операции — следующий запуск начинается с чистого порта. <!-- cite: PR 700, PR 701, PR 702, PR 703 -->
- **Улучшена диагностика и обработка ответов.** Принимаются многострочные ответы платы, а команда Test-Mux выполняет тестовый план — можно проверить подключение без запуска реальной операции. <!-- cite: PR 655, PR 757, PR 787 -->
- **Исправлена гонка при запуске операции.** Одновременный старт нескольких устройств стенда больше не приводит к перезаписи параметров друг друга. <!-- cite: PR 788 -->

## v1.0.0

- **Плагин добавлен.** Создавайте профили Board с типизированными параметрами и запускайте их через драйвер Mux. <!-- cite: PR 282, PR 286, PR 376 -->
- **Более устойчивый конвейер команд.** Сбой или таймаут команды KZ больше не ломает остальной план; некорректные или отсутствующие ответы платы дают пустые параметры вместо падения операции; команды профиля без инструкции тихо пропускаются; индивидуальные сдвиги ожидания устраняют потерю ранних ответов. <!-- cite: PR 571, PR 580, PR 584, PR 600, PR 603, PR 605, PR 625 -->
- **Стартовые параметры из профиля.** Значения, введённые в мастере новой операции, попадают в план платы как именованные параметры. <!-- cite: PR 590 -->
- **Корректное поведение кнопок Submit / Cancel в настройках драйвера.** Кнопки остаются недоступными и серыми, пока действительно не появятся изменения. <!-- cite: PR 597 -->
