# Test Operations Plugin — Изменения для пользователя

Плагин предоставляет два интерфейса операций:

- **General** (`apps/test`) — универсальный стенд для прогона процесса при интеграции и приёмке;
- **TypeOne** (`apps/typeone`) — проверка тока потребления сенсора, в том числе вариант MipTech.

Оба запускаются в окне операции во время выполнения задачи.

## v2.0.2

- **Монитор операции открывается надёжно.** Запуск окна монитора операции снова открывается корректно. <!-- cite: 289e0e9 -->

## v1.13.0

- **Переработан интерфейс TypeOne.** Более чистая компоновка с крупными живыми показаниями, индикатор pass/fail для каждого сенсора и панель журнала в реальном времени рядом с таблицей сенсоров; индикатор теперь следует за последним значением, даже если показания приходят не по порядку. <!-- cite: PR 786, PR 789, PR 808, PR 810, PR 812 -->
- **Ограничение частоты опроса сенсоров.** Если профиль запрашивает больше опросов в секунду, чем выдаёт устройство, лишние опросы отбрасываются вместо бесконечной очереди. <!-- cite: PR 778 -->

## v1.12.5

- **Исправления живого экрана и настроек.** Параметры TypeOne сохраняются по кнопке Save, на живом экране снова показываются все настроенные сенсоры, а пропущенные сенсоры отображаются как пропущенные, а не как неуспешные. <!-- cite: PR 587, PR 599, PR 601 -->
- **Универсальная панель управления.** Общая панель Start / Cancel / Done, как в Optogen и основном приложении. <!-- cite: PR 558 -->

## v1.12.0

- **Доработки MipTech.** Журнал автоматически прокручивается к последней записи, успешные сенсоры подсвечиваются зелёным, в отчёте фиксируется серийный номер изделия для каждого запуска, а живые показания обновляются с меньшим мерцанием при долгих прогонах. <!-- cite: PR 583, PR 588, PR 592 -->
- **Конфигурация TypeOne из профиля.** TypeOne берёт список сенсоров и пределы из профиля операции. <!-- cite: PR 570 -->

## v1.0.0

- **Каркас приложений операций добавлен.** Подключаемый каркас приложений для каждой операции; универсальное приложение Test — первый потребитель. <!-- cite: PR 225, PR 229 -->
- **Зоны аудита из шаблонов и живые данные драйверов.** Приложение читает зоны аудита из активного шаблона и видит подключённые устройства и их параметры из профиля в реальном времени во время прогона. <!-- cite: PR 284, PR 294 -->
