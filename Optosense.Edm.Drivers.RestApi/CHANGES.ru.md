# Драйвер REST API — изменения для пользователя

Драйвер REST API позволяет EDM читать и записывать параметры любого устройства с HTTP/REST-интерфейсом. Плагин включает два экрана: **редактор профиля** (`profiles/restapi`) для описания эндпоинтов и параметров и **редактор параметров драйвера** (`drivers/restapi`), который открывается при подключении драйвера к устройству на рабочем месте.

## v1.13.22

- **Исправлена утечка памяти.** Длительные операции с драйвером REST API больше не накапливают память между запросами. <!-- cite: PR 837 -->

## v1.13.0

- **Более надёжный обмен параметрами.** Каждый запрос теперь дожидается своего ответа до отправки следующего, а параметр длинного опроса получил понятное имя в профиле. <!-- cite: PR 717, PR 718 -->

## v1.12.0

- **Плагин впервые выпущен.** Опишите REST-эндпоинты в профиле, подключите драйвер к устройству — и EDM будет вызывать настроенные GET/PUT/POST для чтения и записи параметров во время операции. <!-- cite: PR 582 -->
- **Понятное поведение кнопок Сохранить и Отмена.** Кнопки в параметрах драйвера остаются неактивными и серыми, пока вы действительно что-то не измените. <!-- cite: PR 597 -->
